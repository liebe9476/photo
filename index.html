TM-m30III 연결 문제 해결 가이드

1. 블루투스(BLE) 검색이 안 될 때

  • 안드로이드: [설정] > [위치(GPS)]가 켜져 있어야 BLE 장치 검색이 허용됩니다.
  • 다른 폰이나 포스기에 이미 블루투스가 물려있으면 검색되지 않습니다. (1:1 접속 해제 필요)
  • 프린터 전원을 껐다 켠 후 피드(FEED) 버튼을 길게 눌러 Bluetooth 페어링 대기 상태인지 확인하세요.

2. USB 케이블 연결 시 "장치를 찾을 수 없음" 또는 거부될 때

  • OTG 젠더가 정상 지원되는지 확인하세요 (데이터 통신 가능 케이블 필수).
  • 팝업이 뜨면 [Epson TM-m30III]를 선택 후 '연결'을 누르세요.
  • WebUSB 접근이 차단된 경우, 본 앱은 Web Serial 가상 포트로 자동 전환하여 재시도합니다.

3. 아이패드(iPad) Safari 환경인 경우

Safari 브라우저는 Apple 정책상 Web Bluetooth를 차단합니다. [Bluefy] 앱을 통해 접속하시거나, 하단의 [시스템 브라우저 인쇄]를 누르면 즉시 AirPrint로 고화질 출력이 가능합니다.
