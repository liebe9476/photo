TM-m30III 연결 문제 해결 가이드

1. 블루투스(BLE) 검색 목록에 프린터가 안 뜰 때 (필독)

  • 위치(GPS) 켜기 (안드로이드 필수): 안드로이드 보안 정책상 [설정] > [위치]가 켜져 있어야 주변 BLE 블루투스 장치 스캔이 허용됩니다.
  • 1:1 페어링 점유 해제: TM-m30III는 동시에 1대의 기기만 연결 가능합니다. 스마트폰, 다른 태블릿, POS 기기에 이미 블루투스로 연결되어 있다면 해당 기기에서 블루투스를 끄거나 등록을 해제하세요.
  • OS 설정 페어링 해제: 태블릿 자체 [설정] > [블루투스] 목록에 이미 기기가 등록되어 있으면 브라우저 스캔 목록에 안 나타날 수 있습니다. '등록 해제(이 기기 지우기)' 후 웹앱에서 직접 검색하세요.

2. USB 케이블 직결 시

  • 충전 전용이 아닌 데이터 전송 가능 USB 케이블을 사용하세요.
  • 팝업이 뜨면 [Epson TM-m30III]를 선택 후 '연결'을 누르세요.
  • WebUSB 접근이 차단된 경우, 본 앱은 Web Serial 가상 포트로 자동 전환하여 재시도합니다.

3. 블루투스 연결 없이 바로 인쇄할 때

태블릿 자체에 TM-m30III를 블루투스로 미리 페어링해 두셨다면 [시스템 브라우저 인쇄 다이얼로그 열기]를 누르면 별도 연결 작업 없이 영수증만 정확히 인쇄됩니다.
